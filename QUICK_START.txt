## 📞 SUPPORT

### Error pada halaman?
1. Check `ecommerce/logs/error.log`
2. Verify database imported (run import.php)
3. Restart PHP/MySQL server

### Database issues?
1. Verify MySQL running
2. Check username/password di config.php
3. Run import script: `database/import.php`

### Login not working?
1. Register akun baru
2. Use exact password
3. Check email/username di database
